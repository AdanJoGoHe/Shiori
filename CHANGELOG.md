## 0.1.0a1 — 2026-10-17 (Git tag v0.1.0-alpha.1)

- Distinct empty/filter/no-read/partial/scan-limit viewer states with accessible retry and safe
  diagnostic codes. Read-only `doctor --catalog` compares registered/readable notes and opaque
  selected-config/store identities. Synthetic PowerShell/CLI/MCP/HTTP and browser regressions.

- Canonical root/child comparisons, post-creation initializer paths and explicit shared-config
  installation on Windows. New read-only `paths` and preview/apply `repair-paths` verify the same
  store, snapshot the prior JSON and refuse empty replacements, links or unresolved identities.

- Global marked-fragment search: category/color filters, verbatim commands/IPs/paths with short
  context, quote-only copy and exact reader navigation with preserved results state. Retained
  missing-document quotes stay repairable without reading outside the catalog.

- Opt-in `doctor --provider` and MCP `memory_status(check_provider=true)` probe current local
  project status without reindexing. Return only observed counts or bounded failure codes;
  cap response size/time and preserve default status behavior.

- Portable isolated Basic Memory adapter, validated result contract and canonical fallback
  diagnostics. MCP status reports the last indexed-search observation; installed-wheel smoke
  now exercises an actual local Basic Memory search instead of only filesystem retrieval.

- `upgrade-codex` previews existing integration changes; explicit `--apply` refreshes owned
  MCP/instruction blocks and packaged skill with recovery snapshots, conflict refusal and
  ordinary write-error rollback. Preserve unrelated settings and subsequent uninstall behavior.

- Spanish installation and user guide with practical workflows, recovery and current limits;
  README links to it and removes outdated remote/catalog statements.

- Manual Release workflow reuses Windows/Linux CI, audits version-matched artifacts and creates
  a draft by default. Publication is opt-in; existing tags/releases are not overwritten.

- First personal Codex alpha: consolidate canonical capture/context, local viewer/annotations,
  recovery and explicit quality preview. Package the portable skill inside the wheel and verify
  installation, removal, CLI, all eight stdio tools, viewer guards and restoration outside source.

- CLI local backup/restore: ordinary canonical files, ledger and current annotation state with
  a bounded SHA-256 manifest; restore to a fresh paused deployment without the original config.
  Existing destinations are never overwritten; incomplete outputs retain no completion marker.

- Read-only capture quality preview over MCP/CLI: explicit privacy/relevance/evidence assessment,
  save/update/journal-only/skip/deny decisions, unverified downgrade and event deduplication.
  Shared capture validation retains write controls; this does not independently verify evidence.

- Capture recovery: prevent new events overtaking pending writes to the same stable note ID;
  expose paginated pending identifiers through MCP and CLI without retaining bodies. Original
  payload retries preserve journal dates and metadata; lost payload recovery remains manual.

- Agent `get_context` MCP tool and CLI `context`: bounded JSON with verbatim body/evidence,
  status, verification age and caveats. Canonical filters, deterministic ranking and default
  historical exclusion require no provider process; existing search remains compatible.

- Reader text selection and literal-text keyboard/touch fallback, multi-tag colored highlights,
  deterministic overlaps, edit/delete/session undo and explicit anchor repair. Text, code and links
  stay intact; unresolved/orphaned marks retain their saved context. Undo restores the original ID
  with a new version and expires with the session or a later deletion.

- Fragment-category manager with Comando, Información importante, Dirección IP, URL and Ruta;
  create/rename/recolor/archive/restore, stable references, duplicate-name normalization and
  version conflicts. Schema 2 exports annotations and categories together; schema 1 reads stay
  unchanged until a deliberate write. Annotation colors remain explicit overrides.

- Display-only annotation anchor resolution with conservative quote/context matching,
  explicit ambiguous/missing/unavailable states, and retained orphan lookup. Reads never
  mutate saved anchors; existing versioned updates support deliberate manual relink.
- Review backlog priorities and execution order, deferring unused hosts and graph/timeline.

- Claro, Oscuro and Café Latte themes with browser-local preference and shared accessible palettes.

- Separate local annotation storage and protected CRUD API, with source revisions, exact text anchors,
  version conflicts, atomic writes/prior snapshot and validated CLI export/restore. Source Markdown
  stays read-only; selection/highlight controls, tag management and fragment search are pending.

- Local read-only visual library with full-text search, combined metadata/date filters, tag controls,
  paging, safe Markdown reader, table of contents and scoped links. Assets stay local; server binds
  loopback with a per-session URL and no write routes. Includes a disposable synthetic demo.

- Bounded read-only content catalog for configured Markdown documentation, canonical notes and
  dated journals, with source-qualified IDs, pagination, redacted source errors and CLI/MCP access.

- Preserve and validate note tags, project, related IDs, references and sensitivity; retain omitted
  metadata on updates. Add combined canonical metadata filters to CLI/MCP search.

- Journal-only progress through the existing capture CLI/MCP boundary, without creating a note.
- Shared pause, secret/scope rejection, locking and event deduplication; retries retain the original
  journal day across partial writes. New synthetic CLI and real stdio MCP-process acceptance tests.
