# Codex personal
The packaged memory skill also supports the [hybrid learning workflow](../../docs/learning.md):
private proposals, reviewed first activation and bounded maintenance of owned skills.
No lifecycle hooks are installed by this adapter.

Run scripts/install-personal.ps1 after installing the local package. The installer adds one stdio MCP entry and a discoverable user skill, backing up existing settings. Restart the app, verify ten Shiori tools, search the git-version note and exercise capture in a normal task. See docs/compatibility.md; fresh-session discovery is not implied by protocol smoke tests.
