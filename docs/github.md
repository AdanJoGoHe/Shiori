# Source and planning on GitHub

- [Source](https://github.com/AdanJoGoHe/Shiori)
- [Issues](https://github.com/AdanJoGoHe/Shiori/issues)
- [Milestones](https://github.com/AdanJoGoHe/Shiori/milestones)

The repository contains source, documentation and synthetic fixtures. Memory data and deployment
state stay outside GitHub. Repository visibility and the planning board's visibility are separate
settings; a public source repository does not require publishing internal planning/history.

Use existing issues and planning IDs when continuing work. Acceptance requires observed evidence;
source implementation alone does not prove real-host support. Follow [CONTRIBUTING](../CONTRIBUTING.md)
for local validation and commit messages and [publication](publication.md) for the public boundary.
The release workflow resolves the repository dynamically and is manually triggered; ordinary
source pushes and PRs do not dispatch Actions.
