# Shiori v0.1.0-alpha.2

Memoria de trabajo separada e instalación preparada para actualizarse desde paquetes locales.
Esta versión sigue siendo alpha; no cambia una instalación existente por sí sola.

- Perfil `work` con vault y estado nuevos emparejados, índice `second-brain-work` y capturas
  que deben declarar el mismo scope. La integración personal existente se conserva.
- Exportación/restauración conservan el scope; importar entre scopes se rechaza antes de escribir.
- Instalador Windows, ruta estable para Augment y entornos por versión. Preview por defecto,
  copia de recuperación antes de activar, rechazo de sesiones abiertas y rollback con comprobación
  de compatibilidad sobre los datos actuales.
- Skill `shiori-work` empaquetada e instalación explícita que respeta archivos ajenos o editados.
- Cinco archivos de release: wheel, fuente, constraints, instalador PowerShell y SHA256SUMS.

Consulta [la guía de Augment y actualizaciones](../augment-trabajo.md). Las validaciones usan
datos sintéticos; la aceptación de una versión concreta de JetBrains/Augment y de sus políticas
en el equipo de trabajo queda por comprobar allí. Los hashes no sustituyen verificar la procedencia.
No se activa conectividad remota ni se mezclan memorias personales y de trabajo.
