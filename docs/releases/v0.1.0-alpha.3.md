# Shiori v0.1.0-alpha.3

El updater busca y descarga versiones publicadas desde el repositorio oficial.

- `update` comprueba la última release estable, sin descargar paquetes ni modificar archivos.
- `update --prerelease` incluye alphas, betas y candidatas publicadas. Los borradores se excluyen.
- `update --prerelease --apply` descarga wheel, constraints y checksums; comprueba sus tamaños,
  hashes y versión, y usa la instalación por versiones con copia de recuperación y rollback.
- La skill de Augment se refresca con el paquete nuevo si sigue siendo un archivo gestionado.
  Si fue editada, se conserva y el resultado avisa de la revisión manual pendiente.
- Los lanzadores conservan su ruta y se refrescan desde el paquete elegido. Sus copias anteriores
  se incluyen en la recuperación. La actualización desde una carpeta local sigue disponible.

No se instala un servicio ni se actualiza en segundo plano. Cierra MCP y visor antes de aplicar.
La conexión usa la API pública de GitHub sin pedir ni leer tokens. Los hashes comprueban
integridad; no sustituyen revisar la procedencia y las notas de la release.

[Uso e instalación](../augment-trabajo.md). Esta función se incorpora en alpha.3; una instalación
alpha.2 necesita primero actualizar desde los archivos locales de esta release para obtenerla.
La aceptación real en JetBrains/Augment sigue pendiente.
