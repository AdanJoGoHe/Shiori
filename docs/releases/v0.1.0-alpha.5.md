# Shiori v0.1.0-alpha.5

Una alpha para probar el diario y retomar proyectos con menos vueltas.

## Qué trae

- Diario visual por proyecto y fechas, con avances agrupados por actividad e historial.
- Pendientes abiertos, bloqueados, resueltos y descartados. Se pueden reabrir y cada cambio
  conserva su historial; dos sesiones no pueden sobrescribir la misma versión.
- Correcciones enlazadas que conservan la captura original y omisión de avances idénticos
  de una misma actividad y día.
- **Retomar proyecto** y la herramienta MCP `resume_project`, con pendientes actuales,
  último resultado, comprobaciones y próximos pasos.
- Vista móvil con pestañas de avances/pendientes y los temas Claro, Oscuro y Café Latte.
- Skills personal y de trabajo actualizadas para usar este flujo, manteniendo separadas
  ambas memorias. El servidor anuncia diez herramientas MCP.

La [guía del diario](https://github.com/AdanJoGoHe/Shiori/blob/v0.1.0-alpha.5/docs/diario.md)
explica los campos, el seguimiento y los límites.

## Instalar o actualizar

Descarga el wheel y los constraints de esta versión y comprueba `SHA256SUMS`. El instalador
`install-shiori.ps1` prepara una memoria nueva y separada de trabajo; no lo uses para sustituir
una instalación existente.

En una instalación gestionada de trabajo, `shiori.cmd update --prerelease` comprueba la alpha
y `shiori.cmd update --prerelease --apply` la instala. Detén antes MCP y visor para aplicar
el cambio. El updater conserva recuperación y actualiza la skill base si sigue siendo propia
y no está editada. Para el despliegue personal, sigue la
[guía de actualización](https://github.com/AdanJoGoHe/Shiori/blob/v0.1.0-alpha.5/docs/actualizacion.md)
y actualiza su integración desde el Python de destino. Reinicia MCP después: el proceso antiguo
no carga las herramientas o instrucciones nuevas por instalar otro paquete.

Los datos continúan en Markdown y el ledger conserva su esquema. Los backups/restauraciones
incluyen el diario y sus pendientes. No se modifica automáticamente ninguna memoria instalada
por publicar esta release. Los registros de aprendizaje y las skills generadas con `learn`
siguen necesitando conservación aparte de los bundles de memoria.

## Límites de esta alpha

Comprobada en Windows con 517 pruebas locales, 56 pruebas de diario/seguimiento sobre el paquete
instalado y pruebas de navegador en tres tamaños y temas. La actualización desde el paquete
original de alpha.4 y su rollback conservaron notas, marcas y los pendientes creados después
del cambio. Esa alpha.4 era un borrador; no se presenta como un ensayo entre dos releases públicas.

La captura depende de que el agente siga la skill; no hay un registro en segundo plano.
Los estados reflejan lo guardado, no una comprobación independiente. Las consultas tienen límites
y señalan lectura incompleta; los cambios de seguimiento se rechazan si falta historial.
Corregir el texto de una captura no deshace estados: esos requieren su propio cambio explícito.

La aceptación dentro de Augment JetBrains real sigue pendiente en
[la tarea #2](https://github.com/AdanJoGoHe/Shiori/issues/2). Las pruebas de esta release se realizan
en Windows con datos ficticios; no se presenta como una versión estable ni como validación
de Linux, de un equipo de trabajo real o del despliegue remoto entre equipos.
