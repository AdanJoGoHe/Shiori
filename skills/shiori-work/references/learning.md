# Learn a reusable workflow

After verifying a reusable multi-step workflow, read the guide with the configured work CLI
(`shiori.cmd run learn guide` for the managed installation). Use `learn list` to find an existing
workflow ID, then `learn propose --apply` to save a curated private draft. Keep source notes
verified and current. Use the current session and keep private proposals and skills outside Git.

Review new skills, broader behavior, changed sources/projects or new capabilities with the
owner before `learn activate --apply`. Use `learn refresh --apply` for an approved correction on
an unchanged owned destination. Archive deliberately obsolete workflows after review.
